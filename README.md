# Hedge Modularný Manager

Tento repozitár obsahuje modulárne GUI komponenty z `modularny/` projektu Hedge Manager.

- Obsahuje čistý Python kód (tab_* a utils).
- Git tu sleduje len túto zložku, aby sa v separátnom repozitári mohlo vyvíjať oddelene.

Pridaj vlastné `git remote add origin ...` a pushni.
